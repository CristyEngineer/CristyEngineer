📌 Project Overview
This project is a fully developed HVAC/BMS database model for an Air Handling Unit (AHU) system.
It includes:
- a complete relational database schema
- realistic seed data stored in CSV files
- stored procedures
- a data‑loading script
- a clean and professional folder structure

The goal of this project is to demonstrate my ability to:
- design relational databases
- normalize data structures
- write SQL scripts
- import data from CSV files
- build stored procedures
- structure a technical project in GitHub
